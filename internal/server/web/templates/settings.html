Retire every agent

Each machine uninstalls its own agent — service, identity file and binary — and stops reporting. Records are kept so you can watch it happen. Machines that are powered off retire when they next come back.

Reset this instance

Deletes every device, script, run, uploaded file and collected file, and rotates the enrollment token so old agents cannot rejoin. Accounts are kept — you would otherwise be locked out. Agents are not uninstalled: retire them first if that is what you want.
